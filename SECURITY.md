# Security policy

RelayMCP gives an AI agent full control of a handheld, so security reports are very welcome.

**Please report vulnerabilities privately** with GitHub's *Report a vulnerability* button (the repository's Security
tab), not in a public issue. Include steps to reproduce and the impact you see. You'll get an acknowledgement within a
few days.

In scope: anything that lets someone other than the owner's computer control the handheld; anything that runs or
listens away from home; ways around the voice dispatcher's permission modes; weaknesses in enrollment, host-key
pinning, or download verification.

The design and its assumptions are described in [docs/security.md](docs/security.md).

Supported versions: the latest release.
